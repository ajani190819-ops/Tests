# Wave Overhangs

Current version: **0.0.51**. Install with [Orca-Plugins.bat](../../Orca-Plugins.bat), then choose **Wave Overhangs** in **Process → Others → Slicing Pipeline Plugin**. The Plugins dialog Version column reads **0.0.51**.

This is experimental: inspect exported G-code and test a small part before a long print. Run **Wave Overhangs - Check setup** after installing.

Detailed configuration, limitations, troubleshooting, and print history are in the [Tests Repository Documentation Archive](https://docs.google.com/document/d/1XTRAFNzKzrKLyo5BrGinvtbg-RQoNAymHIWEg6Ba7io/edit?usp=drivesdk).
